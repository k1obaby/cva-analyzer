# cva-analyzer
Это приложение для обработки и комплексного анализа электрохимических данных полученных с помощью циклической вольтамперометрии, он автоматизирует рутинные процессы сотрудника. Приложение сократило время анализа и стандартизировало процесс в лаборатории.

## Возможности

- Загрузка и визуализация экспериментальных данных CVA
- Работа с фонами (импорт, вычитание, библиотека фонов)
- Управление базой данных реакций
- Аппроксимация пиков различными методами
- Расчет гаммы (Γ)
- Анализ зависимостей от скорости сканирования
- Экспорт данных в различных форматах

## Требования

- **ОС**: Windows 7 SP1/8/10/11 (x64)
- **Дополнительное ПО**: Не требуется (приложение самодостаточное)
